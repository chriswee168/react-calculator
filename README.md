# React Calculator

A simple React calculator that can perform basic mathematical calculations adhering to the BODMAS rule and showcases a first attempt in developing a React app.

## Table of Contents
1. [Dependencies](#dependencies)
2. [Installation/Usage](#installationusage)

## Dependencies
This project requires the following versions of Node.js and npm to be installed:  
- Node.js: **v25.9.0**
- npm: **v11.12.1**

Compatible web browsers (Chromium based):
- Google Chrome
- Opera
- Brave
- Vivaldi

Incompatible web browsers:
- Firefox

Node.js and npm can be installed via the link: https://nodejs.org/en/download

## Installation/Usage
1. To setup up React project run the following command in the root project directory: `npm install`
2. Run the following command to start the React project: `npm run dev`
3. Enter the following URL in a **Chromium** web browser: http://localhost:5173/
4. Use the mouse to enter and calculate equations. Equations must have the correct syntax
(e.g. correct number of opening and closing brackets, equations cannot start and end with operators).
